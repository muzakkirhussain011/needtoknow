# Code of Conduct

wardowl adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in all project spaces: issues, pull requests, discussions and
any event or channel where someone represents the project.

In short: be respectful and constructive, assume good intent, welcome newcomers, and keep
criticism focused on ideas and code rather than people. Harassment of any kind is not tolerated.

## Reporting

Report unacceptable behaviour privately to the lead maintainer at
**muzakkirhussain011@gmail.com**. Reports are handled confidentially. Maintainers follow the
Contributor Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban)
in proportion to the impact of the behaviour.
