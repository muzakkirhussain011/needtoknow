# Contributing

needtoknow is developed in the open, and contributions of every size are welcome: bug reports,
documentation, tests, and new backends or authorizers.

- [Contributing guide](https://github.com/muzakkirhussain011/needtoknow/blob/main/CONTRIBUTING.md):
  setting up, running the tests, and what a pull request needs.
- [Governance](https://github.com/muzakkirhussain011/needtoknow/blob/main/GOVERNANCE.md): how
  decisions are made.
- [Code of conduct](https://github.com/muzakkirhussain011/needtoknow/blob/main/CODE_OF_CONDUCT.md).
- [Security policy](https://github.com/muzakkirhussain011/needtoknow/blob/main/SECURITY.md):
  report vulnerabilities privately.
- [Architecture decision records](https://github.com/muzakkirhussain011/needtoknow/tree/main/docs/adr):
  why the project is built the way it is.

Questions and ideas go to
[GitHub issues](https://github.com/muzakkirhussain011/needtoknow/issues).
